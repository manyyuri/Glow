# 皮肤状态分析（skin-analysis）

## 一、观察维度清单（引导用户逐项描述）

按以下维度请用户描述（能说几个说几个，不必全答）：
1. **出油**：T 区/全脸，程度（无/轻微/明显/很油），时间（上午就油还是下午才油）。
2. **干燥起皮**：部位（脸颊/嘴角/鼻翼），程度，是否紧绷、起皮、有刺痛感。
3. **泛红**：部位（脸颊/鼻翼/颧骨），是否对称、时有时无、遇热/遇刺激加重。
4. **痘痘/闭口**：部位（额头/下巴/脸颊/下颌线），类型（红肿痘/白头/闭口），数量变化。
5. **毛孔**：部位与粗细程度。
6. **暗沉**：整脸暗黄还是局部，熬夜/日晒后是否明显。
7. **光泽**：健康光泽 vs 油光。
8. **敏感刺痛**：是否容易泛红、发烫、刺痛，对什么（换产品/风吹/日晒/热水）敏感。

## 二、肤质判断（综合）

- **油性**：全脸出油明显、毛孔粗大、易长痘。
- **干性**：全脸偏干、紧绷起皮、细纹明显、不易长痘。
- **混合**：T 区油、脸颊干；最常见。
- **敏感**：易泛红/刺痛/发热，耐受差——可叠加在以上任何肤质上（"油敏"、"干敏"等）。

> 判断依据是「多维度综合」，不要只看一个症状就下结论；拿不准时如实说"偏向 X，但需要多观察几天"。

## 三、归因（factors）

结合生活因素找可能的关联（**给出可能、不武断**）：
- **睡眠**：熬夜 → 暗沉、出油、黑眼圈、痘痘加重。
- **饮食**：高糖高油/辛辣/乳制品 → 部分人痘痘加重。
- **天气/季节**：换季干燥 → 起皮泛红；夏天出油多。
- **经期**：生理期前后激素波动 → 下巴/下颌线长痘、出油。
- **换产品/新护肤品**：新品牌、浓度刺激 → 泛红刺痛（考虑过敏/不耐受）。
- **压力/情绪**：皮质醇升高 → 出油、爆痘。
- **清洁不当**：过度清洁破坏屏障 → 又油又干、泛红。

## 四、建议（1–3 条可执行）

按肤质给可执行建议，例如：
- 油皮：温和洁面 + 控油保湿（烟酰胺/水杨酸按耐受）+ 防晒；不要过度去油。
- 干皮：保湿打底（玻尿酸/神经酰胺）+ 锁水面霜 + 防晒；减少强效清洁。
- 混合：分区护理——T 区控油、脸颊保湿。
- 敏感：精简护肤（清洁+保湿+防晒三步），停用刺激性产品，屏障修护（神经酰胺/角鲨烷），避免频繁去角质。
- 泛红/刺痛：先停新护肤品、避免热水洗脸、冷敷舒缓；观察 1–2 天。
- 痘痘：不挤压，温和清洁，必要时含水杨酸/点涂祛痘产品；频发/严重建议看皮肤科。

## 五、趋势判断与记录

- 记录每次观察（log_skin_state），跨天对比：同一部位/症状是好转、加重还是反复。
- 趋势判断原则：**连续 3–5 天的变化才有意义**，单天波动先不急下结论。
- ⚠️ 就医提示：以下情况建议看医生——大面积红肿脓疱、持续刺痛脱皮、突然大面积爆发、伴发热/瘙痒、或自我护理 1–2 周无改善。**不编造医疗结论**，只做日常养护层面的建议。

## 六、引导式提问（帮助用户描述）
"今天皮肤感觉怎么样？是出油、干燥起皮、泛红、长痘、毛孔、暗沉还是有光泽？主要在哪些位置？和昨天比是变好还是变差？最近睡眠/饮食/有没有换护肤品？"

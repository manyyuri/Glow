# 每周清洁方法（weekly-cleaning）

## 一、洗床单（每周）

### 频率
- **每周 1 次**为佳；尘螨过敏、宠物同床、出汗多者可 3–5 天一次。
- 枕套可 2–3 天换一次（脸接触最多，最脏）。

### 水温与方式
- 水温：**60℃ 以上**可有效除螨（若面料允许）；纯棉一般 40–60℃。不能高温的面料用 30–40℃ + 除螨/除菌洗涤剂。
- 洗涤：反面清洗、套洗衣袋（保护面料）；深色与浅色分开。
- 晾晒：**阳光直晒**最好（紫外线杀菌）；阴雨天用烘干机高温烘干或通风阴干。

### 小技巧
- 每两周把被芯、枕芯拿出去晒一晒/通通风。
- 换下的床单及时洗，别堆在椅子上。

## 二、完整打扫（每周一次）

### 分区清单
1. **卧室**：床铺整理、换床单、梳妆台/桌面、地面吸尘拖地、开窗通风。
2. **卫生间**：马桶、洗手台、镜面、淋浴区/浴缸、地漏、毛巾（换洗消毒）、垃圾。
3. **厨房**：台面、水槽、灶台、油烟机表面、冰箱表面、地面、垃圾桶。
4. **客厅/其他**：沙发/茶几、电视柜、地面、窗台、垃圾桶、随手物归位。
5. **玄关/门厅**：鞋子归位、地垫清洁。

### 顺序原则
- **先上后下**：先高处（桌面、台面、窗台），后地面，避免灰尘落回。
- **先干后湿**：先掸灰/吸尘（干），再湿擦、拖地。
- **先里后外**：先卧室后公共区，卫生间/厨房（湿区）靠后，避免把脏水带到干净区。
- **最后收尾**：垃圾统一装袋、地面最后拖，开窗通风。

### 时间分配（一周一次）
- 总预算 60–90 分钟：
  - 换床单 + 卧室整理：15–20 分钟
  - 卫生间：15 分钟
  - 厨房：15 分钟
  - 客厅 + 地面：20–30 分钟
- 可拆成两晚各 30–45 分钟（周三卧室+卫生间，周末厨房+客厅），不容易累。

### 心态提醒
- 不用一次做到"样板间"——**干净有序、能轻松保持**就是胜利。
- 每做完一个分区休息一下，配合音乐/播客更轻松。
- 养成"随手归位、用完即放回"的习惯，大扫除压力会小很多。

## 反问清单
- 家里有几口人/有宠物吗？（床单频率、打扫重点）
- 对尘螨/灰尘过敏吗？（床单水温、吸尘频率要上强度）
- 卫生间/厨房有没有特别难清理的重灾区？

# 晨间护理方法（morning-ritual）

## 总览：晨间三件套
1. 洗脸护肤（皮肤科角度：夜间皮脂+护肤品残留，清晨需要温和清洁）
2. 早饭（规律进食稳定血糖与精力）
3. 梳头（刺激头皮循环，帮助唤醒）

建议顺序：起床 → 温水或清水洁面 → 护肤（水→精华→乳/霜→防晒）→ 早饭 → 梳头。也可先早饭再护肤，按用户作息调整，不必教条。

## 一、洗脸护肤

### 水温与时长
- 水温：**32–35℃ 温水**，接近体温。过热（>40℃）破坏皮脂膜、易敏感；过冷洗不干净。
- 时长：洁面泡沫在脸上停留 **30–60 秒**即可，不用搓太久。
- 频率：早晚各一次即可；**晨间可用清水或极温和洁面**（干皮/敏感皮早晨甚至只用清水），晚间必须彻底卸妆+清洁。

### 洁面产品选择
- 按肤质：
  - 油皮/混油：温和的氨基酸或两性表活洁面，早晚各一次。
  - 干皮/敏感皮：低泡或无泡洁面，早晨清水为主。
  - 痘痘肌：避免强力去脂型（皂基），选温和但含控油成分的。
- 早（晚上没涂防晒/没化妆）：清水或温和洁面。
- 晚（有防晒/彩妆/一天灰尘）：先卸妆（油/膏/水按产品说明），再正常洁面，避免"卸妆=洁面"一步到位。

### 护肤顺序（早晨）
1. 爽肤水/化妆水（轻拍或化妆棉轻擦，补水）
2. 精华（功效型：抗氧化/保湿/美白按需）
3. 乳液或面霜（锁水；油皮用乳液，干皮用面霜）
4. **防晒（最后一步，白天必须）**：出门前 15–30 分钟涂够量（约一元硬币/全脸），户外或强光环境每 2–3 小时补涂。

> 提醒：每步之间等 30–60 秒，给上一道产品吸收的时间；不要层层叠加过快，避免搓泥。

## 二、早饭

### 搭配原则（蛋白质 + 主食 + 蔬果）
- 蛋白质：鸡蛋/牛奶/酸奶/豆浆/瘦肉（稳定饱腹感与上午精力）。
- 主食：全麦面包/燕麦/杂粮粥/红薯（慢碳，避免血糖过山车）。
- 蔬果：一个水果或一份蔬菜（维生素与膳食纤维）。
- 饮品：温水或淡茶/咖啡适量；**不要空腹只喝咖啡**。
- 时间：起床后 1 小时内吃，规律进食养胃。

### 快捷方案（赶时间）
- 3 分钟：牛奶 + 燕麦片 + 一个香蕉。
- 5 分钟：全麦吐司 + 煎蛋/水煮蛋 + 一杯酸奶。
- 前夜备好：隔夜燕麦杯、水煮蛋、洗好的水果。

## 三、梳头

- 数量与力度：**每天 100 下左右**，力度轻柔，以头皮微微发热、舒适为度，不是越用力越好。
- 方向：**从发根向后脑勺、顺着发流方向**梳；长发先从发尾梳开打结，再整体梳。
- 手法：用宽齿木梳/牛角梳/气垫梳；可微微低头，让头皮放松。
- 禁忌：头皮有伤口、红肿、皮炎时减少梳头，避免拉扯；湿发时不要大力梳（湿发脆弱，容易断）。
- 小技巧：早晚各梳 50 下，配合从额头向后的方向按摩头皮，促进循环、缓解紧绷。

## 反问清单（给用户更贴合的指导）
- 你的肤质是油/干/混/敏感？（决定洁面与乳液面霜选择）
- 早上有防晒/化妆习惯吗？（决定是否需要双重清洁）
- 有偏爱的早饭样式或忌口吗？
